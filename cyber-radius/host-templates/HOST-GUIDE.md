# تشغيل «CyberNet» على راوترك — 5 خطوات فقط

```
┌──────────────┐      ملف واحد يُلصَق      ┌───────────────┐
│   Winbox     │ ───────────────────────▶ │ شبكة CyberNet │
│  New Terminal│                          │  تبثّ فوراً   │
└──────────────┘                          └───────────────┘
```

1. افتح **Winbox** وادخل إلى الراوتر (بعنوانه أو MAC).
2. من القائمة اليسرى اضغط **New Terminal** — تفتح نافذة سوداء.
3. انسخ ملف `.rsc` الذي استلمته **كاملاً** والصقه داخل النافذة، ثم اضغط **Enter**.
4. انتظر ثواني حتى يظهر السطر `cyber ok - CyberNet x2` (الرقم = عدد كروت الواي فاي).
5. من جوالك افتح قائمة الشبكات — ستجد **CyberNet** تبثّ؛ جرّب الاتصال بها.

> إذا لم تظهر الشبكة: تأكد أن كرت الواي فاي مفعّل من **Wireless** (الزر الأحمر يعني معطّل).
> لا تعدّل أي سطر داخل الملف — إعادة لصقه كاملاً تعيد ضبطه تلقائياً دون المساس بإعداداتك.

## 0. القاعدة المعمارية الذهبية

كل مصدر خارجي **يُستدعى من الباك إند فقط، أبداً من التطبيق مباشرة**.
المفاتيح سيرفرية، وطبقة `ThirdPartyService` موحدة (مثل `TopupProvider` الموجود)
مع **caching + fallback** — الشبكة اليمنية تتطلب تصميماً يتحمل الانقطاع.
كل رد مُخزَّن مؤقتاً؛ فشل المزود لا يعني فشل الشاشة.

- **Weather مدفوع**: Open-Meteo يكفي مجاناً.
- أي API بـ rate-limit ضيق في مسار الدفع الحي — cache إجباري.

## القسم 1.5 — بوابة SMS ذاتية عبر شريحة محلية (مقترح المالك)

**الخلفية**: بوابات SMS الدولية لا تغطي اليمن عملياً — الحل الذاتي هو الخيار الوحيد الواقعي،
وهو أيضاً الأرخص (باقة رسائل الشريحة فقط، بلا اشتراك API).

**المستودع**: `capcom6/android-sms-gateway` — Apache-2.0، ~6K نجمة، صيانة نشطة.
تطبيق أندرويد يحوّل أي جوال قديم إلى بوابة SMS بـ REST API، بوضعين:
`local` (نفس الشبكة) و`cloud` (الجوال يهاتف خادمنا — يعمل خلف NAT، وهو وضعنا).

### المعمارية المقترحة

```
Laravel Job (queue:sms) ──► بوابة سيرفرية
                                ▲
          الجوال يسحب الطلبات (cloud mode) ويرسل حالة التسليم
                                │
            جوال أندرويد + شريحة بباقة رسائل + WiFi + شاحن دائم
            + auto-start عند الإقلاع + UPS لانقطاع الكهرباء
                                ▼
                    إرسال SMS فعلية + رد حالة التسليم
```

### ترقيات فوق الفكرة الأصلية

- **جوالان احتياطيان**: شريحة شبكة شمال + شريحة شبكة جنوب — العميل يستلم من رقم يشبه شبكته، وتكرار إن تعطل أحدهما
- **الاستقبال**: العميل بلا نت يرسل رقم الكرت برسالة → البوابة تقرؤها → الخادم يفعّل ويرد «تم» — خدمة كاملة بلا إنترنت
- **Rate limiting**: إيقاع إرسال محدود حتى لا تُعلَم الشريحة سباماً
- **جدول مراقبة**: heartbeat من الجوال → تنبيه مشرف إن سكت البوابة
- **استخدامات**: OTP، تأكيد سداد، تنبيه انتهاء/قرب انتهاء الاشتراك، كروت طوارئ

### مهام التنفيذ عند الطلب

خدمة `SmsGatewayService` + جدول `sms_messages` (status/delivery) + queue + rate limiter
+ شاشة إدارة في Filament (حالة البوابات، فشل، إعادة إرسال) + قوالب الرسائل بالعربية.

## القسم 1.6 — سايبر AI: مساعد صيانة وتشغيل لأصحاب المايكروتيك

**المبدأ**: LLM مجاني (Gemini/Groq) + tool-calling فوق طبقة MikroTik API الموجودة.
الذكاء واجهة عربية تقرأ حالة الراوتر الحقيقية — لا يخترع بيانات. التنفيذ بتأكيد المالك فقط.

### المشاكل التي يحلّها

| مشكلة المالك | استجابة سايبر AI |
|---|---|
| «النت بطيء بالليل» | قراءة مؤشرات حية → تشخيص (إشباع نطاق/مستهلك واحد/queue) → اقتراح إصلاح |
| هجمات brute-force على winbox/ssh | كشف → اقتراح حظر/إغلاق منفذ بضغطة |
| مشاركة الكروت بين أجهزة | كشف تعدد MAC على كرت واحد → تنبيه |
| امتلاء DHCP pool | تشخيص + توسيع النطاق |
| فقدان الإعدادات بانقطاع كهرباء | نسخة سحابية تلقائية بعد كل تغيير |
| خوف تحديث RouterOS | توصية إصدار آمن حسب الموديل |
| تشويش لاسلكي | قراءة الضجيج → اقتراح قناة أفضل |
| سؤال عامي «ليش فصلت البارحة؟» | إجابة من سجلات وحالة فعلية |
| تقرير أسبوعي | ملخص أداء/شكاوى/أرباح + توصيات |

### ضمانات

- لا أمر يُنفَّذ على الراوتر إلا بموافقة المالك في التطبيق (قائمة إصلاحات مقترحة)
- سجل تدقيق كامل لكل ما اقترحه ونفّذه
- يعمل معطلاً بأمان: فشل LLM → يظهر «التحليل غير متاح» لا خطأ يعطل التطبيق

### مراجع أفكار — **لا نسخ كود** (تراخيص مانعة)

**قاعدة الترخيص**: MIT/Apache = نسخ حر مع الإشعار. GPL/AGPL = دمج الكود يلزمنا بفتح مصدر
منتجنا كله — **نستلهم المفهوم فقط ونبني بكودنا الخاص**.

- **SAMM** (FreeRADIUS+PostgreSQL): «عقل» المزود — من يدخل/بأي سرعة/كم حصته.
  لدينا `cyber-radius` أصلاً → خريطة تصميم ندرسها لمستوى المشغّل، لا كود ننسخه.
- **CodePagol/ISP-Mikrotik-Billing** (AGPL): Laravel+Filament بنفس تقنياتنا —
  كأن منتجنا بنسخة منافس. ندرس ميزاته (وكلاء/عمولات/webhook-SMS) ولا ننسخ سطراً.
- **NetPilot-Enterprise** (ترخيص مخصص): وحدة راوتر شاملة — مرجع سكوب.
- **HornBill**: إيجار مغلق — قائمة ميزات للاستلهام فقط، يُستبعد كمصدر.

## القسم 3 — TCXC eSIM Exchange: طريق شريحة البيانات

- **المشكلة**: بيع بيانات SIM يتطلب تقليدياً اتفاق مشغّل — مسدود في اليمن.
- **الحل الموجود**: TelecomsXchange (TCXC) — سوق جملة: API واحد لكل مزودي eSIM الدوليين، أسعار جملة لحظية، تسوية فورية.
- **النموذج**: نفس منطق كروت الواي فاي — نشتري بالجملة، نبيع بهامشنا، نتحكم بالعمولة.
- **الخطوات عند التنفيذ**: تسجيل CSP → مفاتيح API → كتالوج eSIM داخل تطبيق العميل → شراء فوري بمحفظة → تفعيل بـ QR.
- **البديل المفتوح**: OpenIoTRSP لإدارة eUICC مباشرة — تعقيد GSMA عالٍ، طريق أطول.

## القسم 4 — الهندسة العكسية: حدودها واستخداماتها الشرعية

### الأدوات (كلها مجانية وقوية)

`jadx` (49K★) · `Apktool` (27K★) · `MobSF` (22K★) · `objection` · **apkre** — يحوّل APK إلى OpenAPI 3.0 تلقائياً (تحليل ساكن + التقاط حي بـ Frida/mitmproxy) · **ApkSee** — رؤية شاشات/شبكة/مسارات أي APK.

### الشرعية (صراحة كاملة)

- ✅ قانوني: تطبيقاتنا، أو بإذن كتابي (اختبار اختراق، bug bounty).
- ⚠️ رمادي→محظور: فك تطبيقات المنافسين لسرقة ميزات — يخالف شروطهم ويعرّضنا قانونياً.

### الاستخدامات الذكية الشرعية الثلاثة

1. **تدقيق أمني ذاتي**: apkre على APK الخاص بنا → ما الذي يراه المهاجم؟ نقاط API مكشوفة؟ توكنات مسربة؟ (مهم قبل نشر Google Play الرسمي)
2. **ذكاء تنافسي نظيف**: Mobbin/Screenlane (مكتبات UX مرخّصة لآلاف التطبيقات) + مراجعات المتجر + صفحاتهم التسويقية = خريطة ميزات المنافس كاملة بلا مخالفة.
3. **فهم بروتوكولات مزودين شرعيين**: تحليل ترافيك تطبيقات شركات يمنية لفهم مسارات شحنها — لتبني تكاملاً نظيفاً **بعد** التعاقد الرسمي.

## القسم 5 — ابتكارات لم تُذكر في تحليل الـ APIs

| الفكرة | القيمة |
|---|---|
| **نقاط ولاء** | كل كرت = نقطة → كرت مجاني → ولاء للمنصة لا للمالك — قفل نظامي |
| **باقة طوارئ ساعة** | انقطاعات الكهرباء اليمنية = حاجة حقيقية — سعر رمزي لحظة الحاجة |
| **سوق B2B داخلي** | مالك صغير يشتري حزم كروت مخصومة من مالٍ كبير — جملة داخلية |
| **API عمومي** | فتح `/topup/services` بمفاتيح للمطورين اليمنيين — نصبح بنية تحتية |
| **فوترة مقاهي** | نسخة خفيفة: طابعة حرارية + كروت ساعة — سوق غير مخدوم |
| **شهادة جودة** | LibreSpeed + إشارة → شارة «شبكة مُقيّمة ✅» تظهر في العميل |
| **عيادة شبكة ذكية** | Gemini يحلل MikroTik دورياً → إشعار استباقي للمالك |
| **كرت QR** | طباعة QR على الكرت → مسح = دخول فوري بلا كتابة |
| **OCR إيصال بنكي** | صورة → قراءة المبلغ/الحساب → تعبئة طلب الدفع تلقائياً |

## القسم 7 — أسئلة مفتوحة على المالك

- مفتاح Gemini/OpenRouter: تسجيل حساب مجاني — هل لديك حساب Google نسجّل به؟
- TCXC: تسجيل CSP رسمي — هل وثائقك التجارية جاهزة (سجل/رخصة)؟
- LibreSpeed: نستضيفه على نفس خادم staging أم نفصله على نطاق فرعي؟
- فحص apkre: يُنفَّذ على `app-debug.apk` محلياً — مناسب للبدء الآن؟
- هل عمولة eSIM ثابتة أم نسبة؟ وهل نبدأ بالدفع المحفظي فقط؟

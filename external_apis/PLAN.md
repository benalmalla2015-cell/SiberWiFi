## 0. القاعدة المعمارية الذهبية

كل مصدر خارجي **يُستدعى من الباك إند فقط، أبداً من التطبيق مباشرة**.
المفاتيح سيرفرية، وطبقة `ThirdPartyService` موحدة (مثل `TopupProvider` الموجود)
مع **caching + fallback** — الشبكة اليمنية تتطلب تصميماً يتحمل الانقطاع.
كل رد مُخزَّن مؤقتاً؛ فشل المزود لا يعني فشل الشاشة.

### تشغيلية/تجربة

| **Optiic** | apiKey — OCR بديل + ترجمة |
| **Open-Meteo** | بلا مفتاح — ودجت طقس للمالك (الوصلات اللاسلكية تتأثر فعلياً) |
| **Geoapify** | apiKey مجاني — خريطة نقاط الشحن والتغطية (OSM) |

### ما لا ننصح به — صراحة هندسية

- **SMS APIs** (TextKit وغيرها): كلها US/CA — لا تغطي اليمن. FCM كافٍ.
- **Weather مدفوع**: Open-Meteo يكفي مجاناً.
- أي API بـ rate-limit ضيق في مسار الدفع الحي — cache إجباري.

## القسم 3 — TCXC eSIM Exchange: طريق شريحة البيانات

- **المشكلة**: بيع بيانات SIM يتطلب تقليدياً اتفاق مشغّل — مسدود في اليمن.
- **الحل الموجود**: TelecomsXchange (TCXC) — سوق جملة: API واحد لكل مزودي eSIM الدوليين، أسعار جملة لحظية، تسوية فورية.
- **النموذج**: نفس منطق كروت الواي فاي — نشتري بالجملة، نبيع بهامشنا، نتحكم بالعمولة.
- **الخطوات عند التنفيذ**: تسجيل CSP → مفاتيح API → كتالوج eSIM داخل تطبيق العميل → شراء فوري بمحفظة → تفعيل بـ QR.
- **البديل المفتوح**: OpenIoTRSP لإدارة eUICC مباشرة — تعقيد GSMA عالٍ، طريق أطول.

## القسم 4 — الهندسة العكسية: حدودها واستخداماتها الشرعية

### الأدوات (كلها مجانية وقوية)

`jadx` (49K★) · `Apktool` (27K★) · `MobSF` (22K★) · `objection` · **apkre** — يحوّل APK إلى OpenAPI 3.0 تلقائياً (تحليل ساكن + التقاط حي بـ Frida/mitmproxy) · **ApkSee** — رؤية شاشات/شبكة/مسارات أي APK.

### الشرعية (صراحة كاملة)

- ✅ قانوني: تطبيقاتنا، أو بإذن كتابي (اختبار اختراق، bug bounty).
- ⚠️ رمادي→محظور: فك تطبيقات المنافسين لسرقة ميزات — يخالف شروطهم ويعرّضنا قانونياً.

### الاستخدامات الذكية الشرعية الثلاثة

1. **تدقيق أمني ذاتي**: apkre على APK الخاص بنا → ما الذي يراه المهاجم؟ نقاط API مكشوفة؟ توكنات مسربة؟ (مهم قبل نشر Google Play الرسمي)
2. **ذكاء تنافسي نظيف**: Mobbin/Screenlane (مكتبات UX مرخّصة لآلاف التطبيقات) + مراجعات المتجر + صفحاتهم التسويقية = خريطة ميزات المنافس كاملة بلا مخالفة.
3. **فهم بروتوكولات مزودين شرعيين**: تحليل ترافيك تطبيقات شركات يمنية لفهم مسارات شحنها — لتبني تكاملاً نظيفاً **بعد** التعاقد الرسمي.

## القسم 5 — ابتكارات لم تُذكر في تحليل الـ APIs

| الفكرة | القيمة |
|---|---|
| **نقاط ولاء** | كل كرت = نقطة → كرت مجاني → ولاء للمنصة لا للمالك — قفل نظامي |
| **باقة طوارئ ساعة** | انقطاعات الكهرباء اليمنية = حاجة حقيقية — سعر رمزي لحظة الحاجة |
| **سوق B2B داخلي** | مالك صغير يشتري حزم كروت مخصومة من مالٍ كبير — جملة داخلية |
| **API عمومي** | فتح `/topup/services` بمفاتيح للمطورين اليمنيين — نصبح بنية تحتية |
| **فوترة مقاهي** | نسخة خفيفة: طابعة حرارية + كروت ساعة — سوق غير مخدوم |
| **شهادة جودة** | LibreSpeed + إشارة → شارة «شبكة مُقيّمة ✅» تظهر في العميل |
| **عيادة شبكة ذكية** | Gemini يحلل MikroTik دورياً → إشعار استباقي للمالك |
| **كرت QR** | طباعة QR على الكرت → مسح = دخول فوري بلا كتابة |
| **OCR إيصال بنكي** | صورة → قراءة المبلغ/الحساب → تعبئة طلب الدفع تلقائياً |

## القسم 7 — أسئلة مفتوحة على المالك

- مفتاح Gemini/OpenRouter: تسجيل حساب مجاني — هل لديك حساب Google نسجّل به؟
- TCXC: تسجيل CSP رسمي — هل وثائقك التجارية جاهزة (سجل/رخصة)؟
- LibreSpeed: نستضيفه على نفس خادم staging أم نفصله على نطاق فرعي؟
- فحص apkre: يُنفَّذ على `app-debug.apk` محلياً — مناسب للبدء الآن؟
- هل عمولة eSIM ثابتة أم نسبة؟ وهل نبدأ بالدفع المحفظي فقط؟
